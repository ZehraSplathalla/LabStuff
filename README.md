# LabStuff
What effect did I use?
I used the transparency example (mostly using the lecture slides to help out with seeing which nodes were which)
What new elements did I add?
Well, I messed with the colors and float values quite a bit, but what I also did was add some casting shadows & a clear coat. The shadows don't show, & the clear coat would really only show on a plane of some kind, but I still say it was a good idea to add it. Plus, experimenting with the values of the Line Speed & Frequency led to some cool looking effects.
